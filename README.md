# Sharefolio - Track Your Investments Like a Pro

A share portfolio tracker that computes performance metrics across multiple exchanges and currencies. Built with Python and Flask, it parses trade and dividend data, fetches historical prices via yfinance, and presents interactive charts and tables through a web UI.

Key features: FIFO cost-basis accounting, multi-currency support (AUD, USD, TWD, CAD), daily P&L history, and periodic performance snapshots (monthly/quarterly/annual).

This project is open source — feel free to clone the repo or [download the Mac app](https://ivan-yeh.github.io/sharefolio.html).
